# 🔐 Password Generator

A simple random password generator built with vanilla JavaScript. Generates an 8-character password combining numbers, lowercase, uppercase, and special characters.

## 🔗 Demo

👉 [Try it here](https://fredson-sy.github.io/gerador-de-senhas/)

## 📸 Screenshot

![Password Generator](img/image-from-the-website)

## ✨ Features

- One-click random password generation
- Combines numbers, lowercase, uppercase letters, and special characters
- Read-only output field (prevents accidental edits)

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## ⚙️ Running Locally

\`\`\`bash
git clone https://github.com/Fredson-Sy/gerador-de-senhas.git
cd gerador-de-senhas
python -m http.server 8080
\`\`\`

Then open `http://localhost:8080` in your browser.
